# Changelog

Все важные изменения в проекте будут документированы в этом файле.

## [1.1.0] - 2025-12-30

### Добавлено
- 🌐 **Мультиязычность**: Поддержка русского и казахского языков
- 🔄 **Переключатель языка**: Удобный переключатель в интерфейсе
- 💾 **Сохранение языка**: Выбранный язык сохраняется между сеансами
- 📱 **Локализованное форматирование**: Числа форматируются согласно выбранной локали
- 🎯 **Полный перевод**: Все строки интерфейса переведены на оба языка

### Улучшено
- Пользовательский интерфейс теперь доступен на двух языках
- SharedPreferences для хранения настроек
- Автоматическая генерация локализации через flutter gen-l10n

### Технические изменения
- Добавлена зависимость flutter_localizations
- Добавлена зависимость shared_preferences
- Создан LanguageService для управления языками
- Создан LanguageSwitcher виджет
- ARB файлы для русского и казахского языков

## [1.0.0] - 2025-12-30

### Добавлено
- Первоначальный релиз приложения Kaspi Analyzer
- Парсинг PDF выписок Kaspi Gold
- Подсчёт количества уникальных получателей
- Подсчёт общей суммы переводов
- Полностью оффлайн режим работы
- Приватность - данные не покидают устройство
- Поддержка Android 5.0+ (API 21+)
- Интуитивный пользовательский интерфейс
- Автоматическое определение периода выписки
- Clean Architecture с разделением на слои
- Comprehensive тестирование
- ProGuard оптимизация для Android
- Полная документация (ARCHITECTURE.md, CONTRIBUTING.md)

### Функции
- Распознавание переводов людям по именам
- Распознавание переводов на карты других банков
- Исключение оплаты кредитов, покупок и комиссий
- Форматирование сумм с разделителями тысяч
- Корректное склонение слова "человек"
- Валидация файлов (тип, размер до 50 МБ)
- Timeout защита (60 секунд)
- Custom exceptions для обработки ошибок
- Immutable data models
- Кэшированные RegExp паттерны
