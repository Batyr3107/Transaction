# Быстрый старт

## 🚀 Запуск за 3 шага

### 1. Установите зависимости

```bash
flutter pub get
```

### 2. Запустите на эмуляторе/устройстве

```bash
flutter run
```

### 3. Соберите APK

```bash
flutter build apk --release
```

APK находится в: `build/app/outputs/flutter-apk/app-release.apk`

---

## 📱 Как использовать

1. Откройте приложение
2. Нажмите "Загрузить выписку"
3. Выберите PDF файл выписки Kaspi Gold
4. Посмотрите результаты:
   - 👥 Количество людей
   - 💸 Общая сумма

---

## 🔧 Требования

- Flutter SDK 3.0+
- Android Studio
- Android устройство/эмулятор API 21+

---

## 📦 Публикация

### Google Play Console

1. Создайте аккаунт ($25)
2. Соберите AAB:

```bash
flutter build appbundle --release
```

3. Загрузите в Google Play Console
4. Заполните описание, скриншоты, иконку
5. Опубликуйте

---

## ❓ Проблемы?

Проверьте:
- Flutter установлен: `flutter doctor`
- Устройство подключено: `flutter devices`
- Зависимости установлены: `flutter pub get`
